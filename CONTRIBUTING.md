# Contributing to RugScore Bot

Thanks for your interest in contributing! Here's how to get started.

## Getting Started

1. Fork the repo
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/RugscoreBotTG.git`
3. Create a branch: `git checkout -b feature/your-feature`
4. Set up your environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   # Fill in your keys
   ```

## Development

- Follow the existing code style
- Keep functions focused and well-documented
- Add type hints where appropriate
- Test your changes before submitting

## Pull Requests

1. Commit your changes with clear messages
2. Push to your fork
3. Open a PR against `main`
4. Describe what your PR does and why

## Reporting Issues

- Use GitHub Issues
- Include steps to reproduce
- Include relevant logs if applicable

## Code of Conduct

Be respectful. We're all here to build cool stuff.
